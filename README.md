# 📚 Dots and Boxes - Classroom Edition

A modern, multiplayer web-based version of the classic Dots and Boxes game, featuring real-time gameplay via Firebase, global chat, and a premium "Classroom" aesthetic.

## 🚀 Getting Started

To run the game locally on your machine, follow these simple steps:

### Prerequisites
You will need **Node.js** installed on your computer to use the development server.

### Running the Server
The easiest way to view the game is using the `serve` package via `npx`. Run the following command in your terminal from the project root:

```powershell
npx serve . -l 3000
```

Once executed, open your browser and go to:
**[http://localhost:3000](http://localhost:3000)**

## 🎮 Game Features
- **Local Game**: Play with 2-4 players on the same device.
- **Multiplayer Rooms**: Create a private room and invite classmates with a 4-letter code.
- **Quick Match**: Find a random opponent instantly.
- **Global Chat**: Talk to everyone online (Google Sign-in required).
- **Theme Support**: Switch between light and dark classroom themes.
- **Responsive Design**: Play on Desktop, Tablet, or Mobile.

## 🛠️ Technology Stack
- **Frontend**: Vanilla HTML5, CSS3, and JavaScript.
- **Backend**: Firebase Realtime Database for game synchronization.
- **Authentication**: Firebase Authentication (Google Sign-in).
